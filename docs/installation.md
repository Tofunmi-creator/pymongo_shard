# Installation

## Stable release

To install pymongo_shard, run this command in your terminal:

```sh
uv add pymongo_shard
```

Or if you prefer to use `pip`:

```sh
pip install pymongo_shard
```

## From source

The source files for pymongo_shard can be downloaded from the [Github repo](https://github.com/Tofunmi-creator/pymongo_shard).

You can either clone the public repository:

```sh
git clone git://github.com/Tofunmi-creator/pymongo_shard
```

Or download the [tarball](https://github.com/Tofunmi-creator/pymongo_shard/tarball/master):

```sh
curl -OJL https://github.com/Tofunmi-creator/pymongo_shard/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd pymongo_shard
uv pip install .
```
